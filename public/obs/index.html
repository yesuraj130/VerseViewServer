OBS Studio Quick Setup:

  1. In OBS Studio, click + under the Sources dock and choose Browser.
  2. Set the URL to any of the endpoints above (e.g. http://<your-server-ip-or-host>/obs/1 or /obs/2).
  3. Set Width to 1920 and Height to 1080 (or your stream canvas resolution).
  4. Check "Shutdown source when not visible" and "Refresh browser when scene becomes active" if desired.
  5. Click OK. The browser source will instantly receive real-time lyrics and scriptures with zero configuration.
